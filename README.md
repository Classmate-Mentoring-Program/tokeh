# Xevi

**Xevi** is an open Natural Language Processing (NLP) project for **Fongbé**.
**Xevi** is derived from the Fon word **_xɛví_**, meaning **"bird"** 🐦 a symbol of communication, language, and the free exchange of ideas.

I'm building this project for personal purposes and my willingness to understand and contribute to the emerging NLP ecosystem for Fongbé. I hope this project will be useful.

## Getting Help

If you have a question, encounter a bug, or would like to suggest a new feature, feel free to open an **Issue** or start a **Discussion** here on GitHub.

## Contributing

Contributions of all kinds are welcome! Whether you're fixing bugs, improving documentation, proposing new features, or implementing new NLP components, your help is greatly appreciated.
If you'd like to contribute, please open an issue to discuss your idea or submit a pull request. We value clear, well-tested, and well-documented contributions.
