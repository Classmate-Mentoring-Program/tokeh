# Xevi

**Xevi** is an open-source Natural Language Processing (NLP) library for building clean, modular, and reproducible text processing pipelines for Fongb and compatible with [NLTK](https://github.com/nltk/nltk).
**Xevi** is derived from the Fon word **_xɛví_**, meaning **"bird"** 🐦 a symbol of communication, language, and the free exchange of ideas.
